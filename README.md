# Дуплет

Сайт паблика Counter-Strike 1.6. На главной — подключение к серверу и мониторинг. В отдельных разделах — ранги, бан-лист и Steam VIP.

## Запуск

Нужен Node.js 24. Скопируй `.env.example` в `.env` и выполни команды:

```sh
npm ci
node --env-file=.env server.mjs
```

Сайт открывается на `http://127.0.0.1:8787`. Укажи адрес сервера в `SHOROH_GAME_ADDRESS`. Для рангов и банов заполни настройки SFTP либо укажи общий каталог данных игры в `SHOROH_GAME_DATA_DIR`.

Бан-лист хранится в локальной SQLite. При заполнении `SHOROH_BANS_MYSQL_*` сайт также выгружает баны и разбаны в таблицу `duplet_bans`. Для самоподписанного TLS-сертификата укажи его PEM-файл и сверенный отпечаток SHA-256.

Для публичного доступа запусти Node.js на хостинге и настрой HTTPS-прокси. GitHub Pages раздаёт статические файлы, поэтому сам по себе не запускает мониторинг, ранги и бан-лист. Настройки оплаты и связи с сервером перечислены в `.env.example`.

Тесты — `npm test`.
